# Machine Learning Lab – Day 4: KNN Classification

## Overview
This experiment implements the K-Nearest Neighbours (KNN) algorithm to classify Iris flower species using scikit-learn.

## Dataset
The Iris dataset is included in scikit-learn. It contains 150 flower samples from three species: Setosa, Versicolor, and Virginica.

## Topics Covered
- Introduction to KNN classification
- Euclidean distance and nearest-neighbour voting
- Loading and exploring the Iris dataset
- Train-test splitting
- Building a KNN classifier
- Displaying correct and incorrect predictions
- Model evaluation using accuracy, confusion matrix, and classification report
- Comparing different values of k
- Comparing Euclidean and Manhattan distance metrics

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- scikit-learn

## Notebook
`AP24110010276_Exp4_KNN_Iris.ipynb`
