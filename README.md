# Machine Learning Labs

This repository contains my Machine Learning lab programs, practical exercises, and Jupyter notebooks completed as part of my academic coursework.

```text
Machine-Learning-Labs/
```

## Topics Covered
- Machine Learning fundamentals
- Data preprocessing and visualization
- Classification algorithms
- K-Nearest Neighbours (KNN)
- Decision Trees
- Model evaluation and validation

## Tools and Technologies
- Python
- Google Colab
- Jupyter Notebook
- NumPy and Pandas
- Matplotlib
- Scikit-learn

## How to Use
Open the required lab folder and launch the `.ipynb` notebook using Google Colab or Jupyter Notebook.

Run the notebook cells in order to reproduce the practical exercises and outputs.
