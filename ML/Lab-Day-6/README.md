# Machine Learning Lab – Day 6: Correlation, Covariance and PCA

## Overview
This assignment explores covariance and correlation between variables, covariance and correlation matrices, and Principal Component Analysis (PCA) for dimensionality reduction. It also demonstrates PCA with Logistic Regression and explores Linear Regression, Ridge, and Lasso models.

## Topics Covered
- Covariance and interpretation of relationships between variables
- Correlation and covariance matrices
- Visualization of relationships using plots and covariance ellipses
- Principal Component Analysis (PCA)
- Feature standardization using StandardScaler
- Dimensionality reduction using principal components
- Iris dataset exploration
- Logistic Regression with PCA-transformed features
- Model evaluation using a confusion matrix
- Visualization before and after PCA
- Comparison of Linear Regression, Ridge, and Lasso regression

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn
- scikit-learn

## Notebook
`correlation_covariance_pca_Assignment_06.ipynb`

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the cells in order.
3. Review the covariance and correlation calculations, PCA visualizations, and model evaluation outputs.

## Learning Outcomes
- Understand relationships between numerical variables using covariance and correlation.
- Understand how PCA reduces feature dimensions.
- Apply feature standardization and PCA in a machine learning workflow.
- Evaluate classification results using a confusion matrix.
- Explore regularization using Ridge and Lasso regression.
