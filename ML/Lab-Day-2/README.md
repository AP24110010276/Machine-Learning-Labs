# Machine Learning Lab – Day 2: Pandas

## Overview
This lab covers data manipulation and analysis using the Pandas library in Python. It demonstrates Series and DataFrame operations using sample data.

## Topics Covered
- Creating Pandas Series
- Creating DataFrames from dictionaries and arrays
- Selecting DataFrame columns
- Adding and deleting columns
- Selecting rows using labels with `loc`
- Slicing rows
- Adding rows using `concat()`
- Deleting rows using `drop()`
- Removing duplicate records
- Identifying null values
- Sorting DataFrames

## Libraries Used
- Pandas
- NumPy
