# Machine Learning Lab – Day 5: Decision Trees

## Overview
This lab explores Decision Tree classification using the Titanic passenger dataset. It demonstrates how decision trees make predictions and how model complexity affects performance on unseen data.

## Dataset
The notebook uses the Titanic training and test datasets: `train.csv` and `test.csv`.

## Topics Covered
- Introduction to Decision Trees
- Preparing Titanic data for classification
- Encoding categorical features
- Handling missing Age and Fare values
- Training and visualizing Decision Tree models
- Predicting survival using passenger features
- Controlling model complexity with `max_depth`
- Evaluating training and validation accuracy
- Holdout validation
- K-fold cross-validation
- Confusion matrix

## Libraries Used
- NumPy
- Pandas
- scikit-learn
- Graphviz
- Matplotlib

## Notebook
`decision_Tree_Lab_Assignment_05_(AP24110010276).ipynb`

## How to Run
1. Open the notebook in Google Colab.
2. Upload `train.csv` and `test.csv` to the Colab environment, or update the file paths to match their location.
3. Run the cells in order.
4. Review the decision tree visualizations, predictions, and validation results.
