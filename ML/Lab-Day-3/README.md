# Machine Learning Lab – Day 3: Matplotlib and Seaborn

## Overview
This lab introduces data visualization using Matplotlib and Seaborn. The notebook uses a video game dataset to create different plots and explore sales and release-year distributions.

## Topics Covered
- Line plots
- Bar charts and customization
- Count plots
- Pie charts for regional sales
- Histograms
- KDE plots
- Descriptive statistics using Pandas
- Box plots for sales data

## Dataset
The notebook uses `final_vg.csv`, a video game dataset. The notebook includes a command to download the dataset before loading it.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Notebook
`Matplotlib_and_Seaborn_Lab_Day_03(AP24110010276).ipynb`

## How to Run
1. Open the notebook in Google Colab.
2. Run the dataset download cell first.
3. Run the remaining cells in order.
4. Review the visualizations and statistical summaries.
