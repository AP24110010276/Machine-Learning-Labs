# Lab Day 1: NumPy Fundamentals

## Overview
This lab explores NumPy for numerical computing and data manipulation in Python. It includes array creation, array properties, mathematical operations, broadcasting, indexing, slicing, filtering, joining, and splitting.

## Topics Covered
- NumPy arrays and performance comparison
- Array properties and special arrays
- Sequence generation and random numbers
- Reshaping, indexing, and slicing
- Mathematical operations and broadcasting
- Boolean indexing, joining, and splitting arrays
- Image analysis using NumPy, including cropping, flipping, RGB channels, brightness analysis, and thresholding
- Text analysis using tokenization, vocabulary, bag-of-words, word frequency, and cosine similarity
